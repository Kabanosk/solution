## Goal
Three MCP servers the agent uses as tools: `.house/tasks/T004-mcp-tools.md` (D-003, D-004).

## What was done
- Dependency `mcp>=1.12,<2` (resolved 1.30.0). `mcp` 2.x removed `FastMCP`, so it is pinned below 2.
- Package `backend/cfo/mcp_servers/` (named so it never shadows the SDK's `mcp`):
  - `company_db.py` (`CompanyDbTools`): `list_transactions` (since/until/undocumented_only), `get_transaction`, `get_invoice`, `list_teams`, `team_costs` (spend per team/month), `list_cost_metrics` (adds cost_per_unit and month-over-month change, e.g. cloud +50% cost / +3% orders), `list_decisions`, `list_rules`. Writes, only two: `attach_invoice` (refuses unknown transaction, already documented, amount mismatch; on success stores invoice + lines and marks the payment documented) and `record_decision`.
  - `workstations.py` (`WorkstationTools`): `list_workstations`, `list_files`, `search_files` (name + content of text/.eml and uncompressed PDFs), `read_file` (.eml parsed; text; PDF/other as base64), `read_attachment`. Only `Downloads`, `Mail`, `Documents` of an existing employee dir are reachable; refused: other folders (`Private`), `..`, absolute/Windows paths, bad employee slugs, symlinks leaving the folder. Every access, including denied ones (`DENIED <action>`), is written to `access_log` BEFORE content is returned; if logging fails the call raises and returns nothing (fail closed). Results with file content carry `untrusted_content: true`.
  - `hr.py` (`HrTools`): `org_chart`, `get_employee`, `manager_of`, `is_on_vacation`, `who_is_on_vacation`, `escalation_chain` (employee, managers up to CEO, `first_available` not on vacation; D-003). Reads the `employees`/`vacations` tables, so whoever loads the HR CSV (T002) must put it there.
  - `common.py` (repo factory: one short connection per call, optional schema pinning), `__main__.py` (runner).
- Tool classes are plain objects (callable in tests without a transport); `build_server(...)` registers them on `FastMCP`.

## How to run (documented commands, from repo root)
- stdio (default; for local agent / MCP clients):
  `uv run --project backend python -m cfo.mcp_servers company-db`
  also `workstations`, `hr`.
- streamable HTTP (cluster), endpoint `http://<host>:<port>/mcp`:
  `uv run --project backend python -m cfo.mcp_servers workstations --transport streamable-http --host 0.0.0.0 --port 8002`
  Default ports: company-db 8001, workstations 8002, hr 8003.
- Env: `DATABASE_URL` (default compose Postgres :5433), `WORKSTATIONS_ROOT` (default `data/generated/workstations`). The DB must have the schema applied (`cfo.db.migrate`).
