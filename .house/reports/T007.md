## Goal
`cfo/analysis/cost_metrics.py`: monthly series for the D-006 pairs, per-unit cost, `detect_anomalies()` with top invoice/bill lines and a one-sentence explanation; must flag the generated cloud +50% month (`.house/tasks/T007-cost-metrics.md`).

## What was done
- New `backend/cfo/analysis/cost_metrics.py` (pure functions on `CostMetric` / `Invoice`, Decimal maths, no I/O):
  - `monthly_series(metrics, invoices=None)` -> `Series`/`Point` per pair (food, ads, cloud order) with `cost_per_unit` (None when the metric is 0), cost / metric / per-unit change in percent and the anomaly of the month.
  - `detect_anomalies(metrics, invoices=None, cost_growth_pct=20, metric_growth_max_pct=10)` -> `CostAnomaly` list (oldest first). Rule: cost up >= 20% m/m and metric up < 10%; months whose previous cost or metric is 0 (June shutdown) are never flagged. Each anomaly carries up to 3 `drivers` (lines that rose, biggest increase first) and a template sentence, e.g. "Cloud cost for the ordering app rose 50.0% month over month while online orders grew only 2.9%: Log ingestion and retention went from EUR 26.95 to EUR 147.23, cloud cost per online order from EUR 0.88 to EUR 1.28."
  - Line items come from `CostMetric.detail` (`lines` list for cloud, `by_supplier` / flat mapping for food) or from the invoice named by `detail.invoice_number` (ads).
  - `to_api_series(series)` -> `list[cfo.api.schemas.CostMetricSeries]`, the T018 `/v1/cost-metrics` item shape (money strings, one-decimal percent strings, `anomaly {summary, drivers}`). `load_series(repo)` reads a `Repository` (metrics + referenced invoices). T019 wiring: `Collection[CostMetricSeries](items=to_api_series(load_series(repo)))`, filter by `kind`.
- `cfo/agent/investigate.py` (T005) adapted minimally: its own detection and line comparison removed, `detect` now calls `detect_anomalies` on the rows from `gw.cost_metrics()` (newest month per pair only, as before) and builds the same finding dict (`facts`, `top_line`, `explanation`); the LLM fallback is now the analysis sentence. Rule change: before it was per-unit +20% and cost 20 points above the metric, now cost +20% and metric < 10% (same as the T018 stub); the 3 existing agent tests still pass unchanged.
