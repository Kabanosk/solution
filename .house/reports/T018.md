## Goal
`cfo.api` with the demo-flow read endpoints returning marked stub data in final shapes, error model, pagination, CORS, `/healthz`, OpenAPI export and `docs/api.md`: `.house/tasks/T018-api-skeleton.md` (D-005, D-006, D-010).

## What was done
- Package `backend/cfo/api/`: `app.py` (`create_app()`, `app`; CORS with `X-Stub` exposed, `/healthz`, `/` redirects to `/docs`), `errors.py` (`ApiError`, handlers for validation / HTTP / unhandled -> `{"error": {"code", "message"[, "details"]}}`), `schemas.py` (Money, Page, Collection and all response models), `stubs.py` (data), `deps.py` (`LimitParam`, `OffsetParam`, `mark_stub`), `settings.py` (`CORS_ORIGINS`, kept out of `config.py`), `export_openapi.py`, and `routers/` with one module per resource.
- Endpoints (all GET, `/v1`): `kpis`, `forecast/liquidity` (`horizon_days` 7..365 default 90, `granularity` day|week), `costs/by-team` (`from`, `to`), `cost-metrics` (`kind`), `decisions` (limit/offset, `level`, `status`, `action_type`), `decisions/{id}`, `rules` (limit/offset, `active`).
- Conventions: money `{"amount": "1234.50", "currency": "EUR"}` (string decimal), percentages as strings, ISO dates, UTC timestamps, collections `{"items"}`, paginated ones add `total/limit/offset`. Every stub response has `"stub": true` and header `X-Stub: true`.
- Stub numbers come from T002 output: closing balance 32,945.51 (Nov) + December net 9,393.42 = 42,338.93 as of 2025-12-31; forecast reaches -20,430.00 on 2026-06-27 (gap 06-06..07-26); cost pairs are the real monthly series incl. cloud +50.0 % / online orders +2.9 % in December (the only `anomaly`); 6 decisions follow demo steps 2-7 (one pending equipment payment, one approved credit line with `executed_simulated`), 3 rules incl. "I always approve equipment myself".
- `docs/api.md` (conventions, error table, per-endpoint query tables, curl and real response examples generated from the app) and `docs/openapi.json` (exported).
- Deps added: `fastapi`, `uvicorn[standard]`, dev `httpx`. Merged `main`: pyproject conflict resolved by keeping both sides, `uv lock` rerun.
