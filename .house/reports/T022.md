## Goal
Seed Job only: download the bank CSV from the in-cluster file server, then `cfo migrate`, `cfo generate`, `cfo load --reset` against the existing Postgres (`.house/tasks/T022-deploy-db.md`).

## What was done
- `deploy/openshift/db/seed-job.yaml`: Job `cfo-seed`, image `cfo-backend:latest` (ImageStream from T023), `imagePullPolicy: Always`. One container with `command: [python, -c]`:
  1. downloads `SOURCE_CSV_URL` (`http://files:8080/pizzeria-amalfi-bank-statement-2025-v6.csv`, env var, flat in the `sample-data` PVC root as in `challenge/sample-data/`) to `SOURCE_CSV=/tmp/bank-statement.csv` (urllib, no curl needed; the generator reads `SOURCE_CSV`);
  2. builds `DATABASE_URL` from Secret `postgres` keys `POSTGRESQL_USER`, `POSTGRESQL_PASSWORD`, `POSTGRESQL_DATABASE` (URL-quoted), host `postgres:5432`;
  3. clears `/app/data/generated`, then runs `cfo migrate`, `cfo generate --out /app/data/generated`, `cfo load --data /app/data/generated --reset`, stops at the first failure.
  PVC `cfo-data` (T023) mounted at `/app/data`, not defined here. Requests 100m/256Mi, limits 1 CPU/1Gi, `backoffLimit: 3`, `activeDeadlineSeconds: 900`. No `ttlSecondsAfterFinished` on purpose: a TTL-deleted Job would be re-created (and re-seed with `--reset`) by the next `oc apply -k deploy/`.
- `deploy/openshift/db/kustomization.yaml` and one added entry `openshift/db` in the `resources:` list of `deploy/kustomization.yaml`; teammate's resources and labels untouched (the root namespace and `part-of=cfo` label apply to the Job).

  ### Seeding and re-seeding the database
  The Job `cfo-seed` downloads the bank CSV from `http://files:8080/`, applies the schema, generates the synthetic company into the PVC `cfo-data` (`/app/data/generated`, also the workstation files for the MCP server) and loads it into Postgres with `--reset`.
  ```sh
  oc apply -k deploy/                       # first seed (needs the cfo-backend image and PVC cfo-data)
  oc logs -f job/cfo-seed
  oc wait --for=condition=complete job/cfo-seed --timeout=300s
  # re-seed (wipes ALL tables incl. simulator state, back to the 31 Dec 2025 starting point):
  oc delete job cfo-seed && oc apply -k deploy/
  ```
  A Job spec is immutable, so it must be deleted before re-applying. The CSV file name is the env var `SOURCE_CSV_URL` of the Job. Do not re-seed during a live demo.
