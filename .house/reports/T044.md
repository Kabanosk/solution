1. **(20) workstations.py** (confirmed: the old check only compared `folder.parent == edir`, so `Mail -> Private` passed).
   - The company folder must now be its own real path (`edir/<name>` resolves to itself); the fully resolved target must lie inside it. 2. **(27) sim/engine.py** (confirmed).
   - `step` emits exactly one event (`_emit_next`); ties at one timestamp are separate steps. On a running playback `step` still moves the clock by the elapsed real time (`_elapse(emit=False)`) but does not flush overdue events; the next `tick` delivers them. Stepping the last event while running pauses, as `tick` does.
   - `start` and `set_speed` reject NaN, +-inf, zero, negative and non-numbers (`_check_speed`); the CLI `--speed` argument does the same with a clean argparse error.
3. **(P3) cost_metrics.py** (confirmed).
   - A cost rising while the metric stays at zero (0 to 0) is flagged, also when the previous cost was 0 (0 -> 150, 0 orders). A metric restarting from zero (June shutdown to July) is still not flagged.
   - Only consecutive calendar months are compared (also across a year boundary): a gap gives no change percentages and no anomaly.
   - The generated-data test (December cloud +50% as the only flag) still passes.
