# T048 — Interactive Granite chat

The LLM workspace page is now a compact Linear-inspired chat rather than telemetry. The user's latest style instruction supersedes the earlier ChatGPT reference. Visual reference: [Linear Agent documentation](https://linear.app/docs/linear-agent).

The header includes a model dropdown containing only `modelcar-granite-4-0-h-tiny` and New chat. The conversation displays actual streaming content, with Enter/Shift+Enter composition, Stop, retry, copy and scroll-to-latest controls. State survives workspace navigation in memory and is cleared by a reload or New chat. Failed unanswered exchanges are not fabricated as context. The UI uses existing shadcn components/theme tokens and an added textarea primitive. It has no pipeline stages, metrics or pretend chat replies.

Authenticated `/api/chat` GET returns allowed models; POST validates model and bounded conversation history, then calls the supplied OpenAI-compatible endpoint on the server. Upstream SSE is adapted to private/no-store NDJSON. The server handles cancellation, timeouts, malformed/empty streams, JSON fallback and length-limited answers without exposing provider error bodies or hidden reasoning fields. Optional `LLM_CHAT_BASE_URL` and `LLM_CHAT_API_KEY` stay on the server. Input is capped at 256 KiB, 64 messages, 16,000 characters per message and 64,000 total; output is limited to 2,048 tokens with a 120-second timeout. Chat does not read company records, call CFO tools or write Postgres.
