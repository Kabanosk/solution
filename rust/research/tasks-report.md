# Native task recorder

`scout-tasks` ports the durable TaskRecorder operations: continuation-safe open, lookup, filtering, field allowlists, update/status/closure, evidence append, activity recording and listeners, with scoped PostgreSQL notifications. It captures an immutable verified tenant rather than relying on thread-local defaults.

The original TaskRecorder is exercised directly against private local schemas by the characterization harness. **8/8** rust-anything application cases pass (six explicit multi-operation scenarios plus two generated boundary traps). Clock fields generated by PostgreSQL are omitted from the deterministic journal, and closure is represented as a boolean; nested user-supplied timestamps and fields named closed_at remain intact and have an explicit regression scenario. Final durable records are included in the journal.

A real PostgreSQL integration test passes continuation ID preservation, filtering, evidence and step durability, first closure timestamp retention after reopening, field rejection, and notification-listener failure isolation. Formatting/clippy checks pass. This plain library is characterized at the application boundary, without a PyO3 unit gate. It is worker infrastructure; loop handlers and watcher execution remain separate work.

Temporary structural seam: the task store reuses ScoutApi's row-to-JSON converter to preserve NUMERIC and timestamp serialization. Extract that converter into a shared storage adapter only after combined replays pass, without duplicating or changing its behavior.
